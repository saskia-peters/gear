- *Disposition:* accept as-is (pragmatic: admin configures the user-owned tables through user-module ports; Epic 3 settings may move it). *Upstream lesson:* reconcile the architecture-spine admin-hexagon claim.

**F2 — `ListPermissionsByUser` gained a team-role UNION branch, but stale comments still claim "the resolution query never joins user_groups".**

### Diff-scope review (adversarial / edge-case / verification-gap)

**F11 — `/api/v1/admin/recovery/deny` is reachable by any admin-module-code holder (e.g. fuehrende with `users.view`), no `admin.recovery.approve` re-check.**
The outer any-of gate widened; the core `DenyAdminRecovery` has no permission/admin check, unlike approve/pending/request. A non-admin with an admin-module code can deny any pending recovery request. No test drives a non-admin-with-an-admin-code at `/recovery/deny`.
- *Disposition:* **fix-now, high severity.** *Lesson:* widening an outer gate requires re-auditing every per-route gate.

**F12 — "Missing field must not clear everything" guard missing on 2 of 4 replacement-set endpoints.**
`AssignAdminUserGroupMembers` (`admin_users.go:520`) and `AssignUserGroupsHandler` (`admin_rework.go:71`) accept `{}` and silently delete every membership; the sibling roles/qualifications endpoints were hardened against this.
- *Disposition:* **fix-now.** *Lesson:* apply the same empty-body guard to all replace-set endpoints.

**F13 — A fixed qualification's per-user expiry can be cleared to permanent-"valid" on the update path.**
`UpdateUserQualificationExpiry` accepts nil for a fixed assignment (only rejects nil-on-unlimited); the SPA edit path sends null for fixed; the assignment then never expires. Untested end-to-end (tests only pass non-nil values).
- *Disposition:* **fix-now.** *Lesson:* the fixed-requires-expiry rule must hold on update, not just assign.

**F14 — Date-only `expires_at` becomes midnight UTC, so the labelled final day is already expired.**
`nullableTime` parses `YYYY-MM-DD` at 00:00 UTC; a European "gültig bis 31.12" is Abgelaufen from 02:00 CEST on 31.12. Test pins the mechanical parse, not the user-visible boundary.
- *Disposition:* defer (UX/date-semantics decision needed — accept end-of-day or document UTC boundary). *Lesson:* date-only boundary semantics should be decided once.

**F15 — Renaming a base role (e.g. `admin`) silently breaks name-coupled admin detection.**
Base roles are editable; `resolveIsAdmin`/recovery flows hard-code the group name `"admin"`. Renaming disables recovery + IsAdmin while the permission set still grants admin codes.
- *Disposition:* defer (add a base-role name guard or switch to id-based detection). *Lesson:* name-coupled identity is fragile.

**F16 — During the OTP TTL, the user's own correct password fails and feeds the FR-3 lockout counter.**
While an OTP is valid, the password slot is verified against the OTP hash; failures increment the lockout counter, so a password-holder can be 429-locked just as the OTP expires.
- *Disposition:* defer (documented behavior; revisit lockout interaction). *Lesson:* a recovery credential temporarily replacing the real one should not burn the real credential's lockout budget.
