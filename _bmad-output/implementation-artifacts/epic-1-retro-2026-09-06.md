## Findings

### Aggregate views

- **[Fix now] Duplication: `authHeaders()` reimplemented per page (pattern divergence).** Four auth pages each define their own local `authHeaders()` helper reading `SESSION_TOKEN_KEY`: `web/src/pages/AdminRecoveryPage.tsx`, `web/src/pages/ChangePasswordPage.tsx`, `web/src/pages/MfaPage.tsx`, `web/src/pages/ProfilePage.tsx`. `web/src/auth/authState.ts` exports `SESSION_TOKEN_KEY` but not a shared `authHeaders()`. Separate sessions each re-derived the same helper. *Prevents the next:* add a shared `authHeaders()` in `authState.ts` (or a small `web/src/auth/api.ts`) and import it; the epic's own "shared token-key helper" finding (1.7-14) established the pattern for the key but not the header builder.
- **[Defer] God-class growth — test files.** `internal/user/adapters/http/handler_test.go` (2915 lines), `internal/user/adapters/postgres/repository_test.go` (1337), `internal/user/core/service_test.go` (847), `internal/user/core/admin_recovery_test.go` (787) grew large over the epic (git_evidence net: 2915/1337/847/787). `handler.go` (892, 19 funcs) and `repository.go` (780, 41 funcs) are large but organized by section. Not a blocker; flagged for maintainability.
- **[Accept] Architecture delta clean (AD-1 held).** No cross-module imports: a grep of `internal/{user,admin,tools}` shows no module importing another module's packages (only `internal/platform/*` + `internal/user/*` internally). The hexagon boundaries survived 30 commits.
- **[Accept] Admin module is still a placeholder.** `internal/admin/{core,ports,adapters}` are 4–5 lines each. The sidebar shows an ADMIN entry for admin-group users and `/admin` renders a stub ("folgt in Epic 2"); the actual admin module ships in Epic 2. In-scope by design, but worth stating so later retros don't re-flag it.
